Kurultai is a high-speed knowledge retrieval and memory layer for AI agents. It indexes everything across your notes, agent transcripts, and codebase symbol dependencies into a single queryable local SQLite vector database.

CodeGraph / DB

When your coding agent asks "What did we change in the SQL database?", Kurultai coordinates neural context: querying CodeGraph for symbol diffs, Pond for execution logs, and Markdown for design specs.

High-Voltage Synaptic Architecture

Designed for sub-millisecond local RAG. Built on standard SQLite + FTS5 + sqlite-vec without bloated network pipelines.

Index-Time Heavy

Calculates embedding synapses and distills context tags when indexing—not when the agent queries. Optimized RRF (Reciprocal Rank Fusion) fuses FTS and vector results in under 5ms.

Read-Time Light

Agent requests return dense, token-efficient citation views (~400 characters) containing exact code definitions and section offsets, preventing context window saturation.

Write-Time Minimal

The remember tool allows agents to write distilled facts and summaries back into the index, keeping records clean, deduplicated, and structured.

Deep Tech Integrations

Connects natively with Obsidian Vaults, Dayflow timeline logs, Pond agent sessions, local GitHub directories, and CodeGraph symbol trees.

Launch the Tech Stack

Set up your local code memory daemon and wire it into your agentic workspace.

1. Install and Initialize
# Build local binaries cargo build --release # Wire config + Cursor MCP kurultai init --agent cursor
2. Index Sources and Run Daemon
# Trigger full initial sync kurultai index --full # Start the background watcher and API server kurultai daemon --port 8421
