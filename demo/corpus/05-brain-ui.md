# Brain UI

The daemon serves an embedded 3D knowledge graph at `/ui/`: a
cortex-hull-constrained force-directed layout (brain shape), electric
synapse styling, and hover-to-highlight connectivity.

Graphs are tiered (hot/warm/cold, timestamped) so large brains don't ship
every node to the browser at once. Below the brain stage, a secondary
playful design language carries panels and lists.
