# ui/ — Brain UI embedded assets (daemon `GET /ui`)

This directory is the **built** Brain UI surface, embedded into the `kurultai`
binary by `src/http/ui.rs` and served at `http://127.0.0.1:8421/ui/`.

- Entry: `brain.html` (explorer + synapse map)
- Hashed assets: `assets/*` (generated by Vite from `website/`)

Source lives in `website/`. Rebuild with `scripts/build-ui.sh`, then rebuild
the daemon so `/ui` picks up the new assets.

Do not create a second dashboard tree (`website/` product, `web/` auth portal as
brain UI, or `DASHBOARD_HTML` forks).
