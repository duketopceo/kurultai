1Write your first note

Notes are searchable right away (full-text search). Add at least one tag.

    2Import a folder of notes

    Mount a folder of Markdown files at /data/notes (read-only is fine). It is indexed on start and watched for changes.

    docker compose down
# in docker-compose.yml, under volumes:
#   - ~/Documents/notes:/data/notes:ro
docker compose up -d

    Markdown files need at least one tag (frontmatter tags: or a line like #project #idea) to be searchable by default.

    3Pick how it understands meaning

    Keyword search works with no setup. Embeddings add search by meaning.
